## Usage Guidelines

### Image Naming Convention
- Use descriptive names that clearly indicate the content
- Use lowercase letters and hyphens for separators
- Include the context (list, create, edit, details) in the filename

### Image Quality
- All screenshots should be high resolution and clear
- Ensure text is readable in the images
- Use consistent styling and layout across similar images

### Documentation Integration
- Reference images using relative paths in markdown files
- Provide alt text for accessibility
- Use images to supplement text explanations, not replace them

## Maintenance

### Adding New Images
1. Take high-quality screenshots of the admin interface
2. Use descriptive filenames following the naming convention
3. Optimize images for web (compress if necessary)
4. Update this README with new image descriptions

### Updating Existing Images
1. Replace outdated screenshots when interface changes
2. Maintain the same filename for consistency
3. Update any documentation references if needed

### Image Optimization
- Compress images to reduce file size while maintaining quality
- Use appropriate formats (PNG for screenshots, JPG for photos)
- Consider responsive image sizes for different screen resolutions
